This file is a **draft template**. Files in `_drafts/` are never published. To publish an article, copy this file into `_posts/` and rename it with the publication date first, for example `_posts/2026-11-20-hst-on-new-residential-rentals.md`. The part after the date becomes the web address: `northernadvisory.ca/insights/hst-on-new-residential-rentals/`.

Write the article in plain text below the second `---` line. Blank lines separate paragraphs.

## Use two hashes for a section heading

Regular paragraphs are written as normal text. Use **double asterisks** for bold and *single asterisks* for italics. Links look like this: [CRA guidance on the GST/HST new residential rental property rebate](https://www.canada.ca/en/revenue-agency.html).

### Three hashes for a smaller heading

- Bullet points start with a hyphen and a space
- Each bullet on its own line

1. Numbered lists start with a number and a period
2. The numbers can all be 1 and they will still count up

> A blockquote starts with a "greater than" sign. Use it for a key takeaway.

| Item | Before | After |
|---|---|---|
| Tables use pipes | $1,000 | $1,250 |
| And hyphens under the header | $2,000 | $2,500 |

The author box, reading time, publication date, legal disclaimer, and "More insights" links are added automatically.
